# TWEAKS — Arch Linux + GNOME

Окрема гілка з одним скриптом для налаштування робочого столу. **Не запускає `install.sh` або `setup.sh` із гілки ARCH-GNOME** і не змінює драйвери чи розділи дисків.

## Один запуск

Запускай **під звичайним користувачем, у відкритому GNOME-сеансі** (не через `sudo`):

```bash
git clone -b TWEAKS https://github.com/deputat1k/installSoftArch.git tweaks-gnome
cd tweaks-gnome
bash tweaks.sh
```

Скрипт попросить пароль `sudo` для встановлення пакетів. Потім **вийди з облікового запису GNOME і увійди знову** — нові розширення на Wayland не завжди завантажуються без нового сеансу.

## Що налаштовує

1. Кнопки мінімізувати, максимізувати, закрити праворуч у заголовках вікон.
2. Dash to Dock — док унизу, не ховається, значки 46 px.
3. Додатки **Disk Usage Analyzer (Baobab)** і **Disks** для перегляду зайнятого/вільного місця та розділів SSD. У GNOME Files **немає точного аналога Windows-смужок заповнення** в «Цей комп'ютер»; ці програми — надійна альтернатива.
4. Blur my Shell — розмиття GNOME за налаштуваннями розширення.
5. AppIndicator — значки Telegram/Steam та інших сумісних програм у верхній панелі.
6. Just Perfection — додаткові налаштування GNOME без примусової зміни його поведінки.
7. Резервні копії GNOME перед змінами та підсумкові перевірки.

**Сумісність:** GNOME Shell визначається під час запуску. Для Dash to Dock, Blur my Shell і Just Perfection використовується офіційний API [extensions.gnome.org](https://extensions.gnome.org), що повертає реліз, схвалений для конкретної версії GNOME. Перед встановленням перевіряються UUID і `shell-version` архіву. Несумісне розширення пропускається; це не гарантує відсутності багів. AppIndicator береться з офіційного репозиторію Arch і теж проходить перевірку метаданих. Скрипт не вимикає перевірку сумісності GNOME.

**Резервні копії:** `~/.local/share/installSoftArch/tweaks-backups/<дата>/` містять копії налаштувань GNOME та лог. Для повернення налаштувань:

```bash
bash restore-tweaks.sh ~/.local/share/installSoftArch/tweaks-backups/ТУТ-ДАТА-ЗАПУСКУ
```

Це відновлює налаштування, а **не видаляє встановлені пакети**. Існуючі користувацькі файли розширень також копіюються до `previous-extensions/`, якщо вони були.

**Застереження:** `pacman -Syu` оновлює систему перед встановленням потрібних програм. Якщо оновився GNOME, потрібен вихід/вхід. Трей деяких програм, анімації й розмиття можуть мати обмеження в нових GNOME. Якщо розширення не з'явилося, відкрий програму `Extensions` і подивись статус та помилки.
